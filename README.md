# 青雲の志 — お守りと印の図鑑

**[図鑑を開く](https://solavrc.github.io/seiun-guide/)**

「青雲の志 失われた聖餌」のお守り・印・ルーン石を、原文と画像で参照する非公式の図鑑です。

- お守り181系統（通常／強化362件）、印28件、ルーン石24件。
- 通常版・強化版の原文を同じ項目に表示。
- 印そのものに共通ルールを集約。お守り右上の印から参照できます。
- 備考はカードテキストの訂正、具体的な相互作用、共通ルールの例外に限定。

## 読み方

本文は保存した日本語の表記を維持しています。元の装飾タグを除いた説明文・表示テンプレートで、`{0}` 等はゲームが現在値を差し込む部分です。日本語本文と実挙動がずれる場合は、備考で訂正し、一致する他言語の短い原文を添えています。日本語が正しい場合、外国語側だけの誤記は載せません。備考と原文抜粋は、折りたたまず最初から表示します。

印の作用ルールは通常版・強化版で共通です。個々のカード本文に、印のルールと既存の確認例を適用して表示します。「適用」は対象となる処理があること、「一部適用」は複数ある効果のうち一部が対象であることを示します。利益の大きさや、全組み合わせの実測を保証する表示ではありません。「対象外」は本体に増やせる効果がないことを示し、「付与不可」とは区別します。特に悪魔は対象外でも自傷が起こります。

判定を付けないアイコンも、印の共通ルールへのリンクとして使えます。備考のないカードには空欄や定型文を表示しません。

本文基準日は2026-09-01、説明の更新日は2026-09-16です。
