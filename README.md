# 雀魂 青雲の志 失われた聖餌 — お守りと印の図鑑

**[図鑑を開く](https://solavrc.github.io/seiun-guide/)**

「雀魂 青雲の志 失われた聖餌」のお守り・印・ルーン石を、原文と画像で参照する非公式の図鑑です。

- お守り181系統（通常／強化362件）、印28件、ルーン石24件。
- 通常版・強化版の原文を同じ項目に常時表示。
- 名前・本文・備考の検索と、「種類」「レア度」での絞り込み。レア度はお守りだけが対象です。
- 印そのものに共通ルールを集約。右上には有効な天使・悪魔だけを表示。
- 備考はカードテキストの訂正、具体的な相互作用、共通ルールの例外に限定。特定の育成方針や自動化の運用は扱いません。

## 読み方

本文は保存した日本語の表記を維持しています。元の装飾タグを除いた説明文・表示テンプレートで、`{0}` 等はゲームが現在値を差し込む部分です。日本語本文と実挙動がずれる場合は、備考で訂正し、一致する他言語の短い原文を添えています。日本語が正しい場合、外国語側だけの誤記は載せません。備考と原文抜粋は、折りたたまず最初から表示します。

印の作用ルールは通常版・強化版で共通です。右上には天使・悪魔のうち、有効なものだけを表示します。「適用」は対象となる処理があること、「一部適用」は本体の一部の効果が対象となることを示します。分類は共通ルールと既存の確認例に基づきます。

拡張・こだまの一般的な対応表示は省き、計算方法・発動順・コピーや集結の扱い・意外な不発を、具体的な題名と関連印を添えた備考で説明します。備考の印アイコンは説明の対象を示すリンクなので、効かない印も登場します。単なる2回発動やコピーなどの共通説明は、印そのものの項目を参照してください。

対象外・付与不可・未分類のアイコンや、空の備考は表示しません。アイコンのない印が必ず付与不可という意味ではありません。また、悪魔は本体効果を増やさなくても自傷が起こる場合があります。

本文基準日は2026-09-01、説明の更新日は2026-09-16です。
