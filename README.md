# 青雲の志 — お守りと印の図鑑

「青雲の志 失われた聖餌」のお守り・印・ルーン石を、原文と画像で参照する非公式の図鑑です。通常版と強化版を同じ項目にまとめ、備考に挙動と組み合わせの説明を載せています。

- お守り181系統（通常／強化362件）、印28件、ルーン石24件。
- 名前・本文・備考の検索、分類・版・印状態の絞り込み。
- 拡張・こだま・天使・悪魔の状態と、通常版／強化版の違い。

## 読み方

カードの本文は保存した日本語の表記を維持しています。元の装飾タグを除いた説明文・表示テンプレートで、`{0}` 等はゲームが現在値を差し込む部分です。備考は原文と別に表示します。

「有効」「効果なし」は備考に示した対象・効果成分・観測条件での判断です。「条件付き」には本文からの候補を含みます。全相互作用を実測した表ではありません。「未確認」は「効果なし」「付与不可」と別です。通常版と強化版で異なる場合は両者の欄を確認してください。

本文基準日は2026-09-01、注記の更新日は2026-09-15です。ゲームの将来の変更を自動追跡するサイトではありません。
